# ex2_dependency_graph

Этап 2: получение и вывод прямых зависимостей указанной версии пакета Ubuntu APT.
Используется только стандартная библиотека Python 3. Менеджеры пакетов
и сторонние библиотеки для получения зависимостей не используются.

Запуск из корня проекта:

```sh
./run.sh
```

Параметры задаются в секции `[settings]` файла `config.ini`:

| Параметр | Назначение |
| --- | --- |
| `package` | Имя пакета Ubuntu, например `bash` |
| `repository` | URL индекса репозитория `Packages`, `Packages.gz` или `Packages.xz` |
| `test_mode` | При `true` читать индекс из локального файла вместо URL |
| `version` | Точная версия из поля `Version`, включая epoch и суффикс Ubuntu, если они есть |
| `ascii_tree` | Сохранённый параметр первого этапа; на втором этапе выводится список зависимостей |

URL должен вести непосредственно на индекс: один корневой URL архива не задаёт
выпуск Ubuntu, компонент и архитектуру. Эти данные задаются путём индекса,
например `https://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64/Packages.gz`.
В режиме тестового репозитория относительный путь отсчитывается от папки INI.
Булевы значения: `true/false`, `yes/no`, `on/off`, `1/0` без учёта регистра.
Все пять параметров обязательны.

Из индекса выбирается запись с точным совпадением `Package` и `Version`.
Прямые зависимости извлекаются из `Pre-Depends` и `Depends`: по одной группе
на строку, с сохранением ограничений версий, квалификаторов архитектуры и
альтернатив через `|`. Формат описан в
[Debian Policy](https://www.debian.org/doc/debian-policy/ch-relationships.html).

Для `bash` версии `5.2.21-2ubuntu4` из поставляемой конфигурации:

```text
libc6 (>= 2.38)
libtinfo6 (>= 6)
base-files (>= 2.1.12)
debianutils (>= 5.6-0.1)
```

Если зависимостей нет, выводится `Прямых зависимостей нет.`.
Ошибки конфигурации, загрузки, формата индекса и отсутствия указанной версии
выводятся в stderr, код завершения — 1.
Вывод параметров `ключ=значение` относился только к первому этапу и заменён
выводом зависимостей.

Запуск с локальным тестовым репозиторием:

```sh
./run.sh tests/fixtures/config.ini
```

Все тесты и их данные находятся в `tests/`. Общий запуск без доступа к сети:

```sh
./tests/run_tests.sh
```

Структура приложения:

- `src/main.py` — точка входа.
- `src/cli.py` — аргументы, вывод зависимостей и ошибок.
- `src/config.py` — чтение INI.
- `src/validators.py` — проверка параметров с учётом формата APT.
- `src/repository.py` — чтение и распаковка индекса.
- `src/dependencies.py` — разбор записей и извлечение прямых зависимостей.
- `src/errors.py` — исключения приложения.
